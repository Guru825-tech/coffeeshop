 ☕ Coffee Shop Webpage

A modern and responsive **Coffee Shop Website** created using **HTML & CSS**.  
This project is designed with a clean layout to showcase coffee products, menu items, and shop details in a beautiful way.

---

## 📌 Project Overview

The **Coffee Shop Webpage** is a simple front-end project that focuses on creating an attractive UI design.  
It is fully responsive and works well on mobile, tablet, and desktop screens.

---

## ✨ Features

✅ Responsive Design (Mobile Friendly)  
✅ Attractive Coffee Shop UI  
✅ Menu Section with Items & Prices  
✅ About Section for Shop Details  
✅ Contact Section  
✅ Clean Layout and Smooth Styling

- CSS3
